# Repository conventions

- Write all repository documentation in English.
- Write commit messages in English using Conventional Commits.
- Use English for pull request titles and descriptions.
- Keep downloaded source material, CAD files, and generated packaging artifacts in the ignored `packaging-inputs/` and `packaging-results/` directories unless explicitly requested otherwise.
- Distinguish measured results from targets and assumptions. Do not claim that a packing layout is feasible or optimal without the corresponding validation evidence.
